## 🚀 시작하기

1. 위 **최신 버전 다운로드**에서 버전 번호가 적힌 zip 파일을 받으세요.
   - GitHub가 자동으로 붙이는 **Source code** 압축 파일은 실행용이 아니에요.
2. 압축을 푼 뒤 `축구 캘린더.exe`를 실행하세요.
3. 파란 보호 창이 뜨면 위 안내대로 `추가 정보` → `실행`을 누르세요.
4. 처음 실행하면 응원팀을 고르거나, <b>「팀 없이 캘린더로 시작」</b>을 누르면 끝!

## 🔄 업데이트

새 버전이 나오면 프로그램 오른쪽 아래에 알림이 표시돼요. **업데이트 확인**에서 바로 업데이트할 수 있고,<br>
등록한 팀·메모·반복 일정·디자인 설정은 그대로 유지돼요.

## ✨ 이렇게 써요

### 📅 축구 안 봐도 괜찮아요

팀을 고르지 않아도 메모·반복 일정용 바탕화면 캘린더로 바로 쓸 수 있어요.

<p align="center"><img src="images/00-축구없이캘린더로시작.png" width="760" alt="📅 축구 안 봐도 괜찮아요"></p>

### 👀 바탕화면에서 바로 확인

오늘 우리 팀 경기가 있는지 바탕화면만 보면 끝. 결과가 궁금하지 않을 땐 스코어를 숨길 수 있어요.

<p align="center"><img src="images/01-일정과스포일러방지.png" width="760" alt="👀 바탕화면에서 바로 확인"></p>

### 🔍 리그에서 응원팀 찾기

팀 이름이 생각나지 않아도 리그를 눌러 참가팀 목록에서 골라 ON 하면 돼요.

<p align="center"><img src="images/02-리그에서응원팀찾기.png" width="760" alt="🔍 리그에서 응원팀 찾기"></p>

### 🌍 추가 리그와 팀 정리

### 📊 경기 통계와 이벤트

스코어만 보고 닫기 아쉬울 때, 슈팅·점유율부터 골·카드 기록까지 확인해요.

누가 뛰었는지, 지금 리그에서 몇 위인지 한 화면에서 볼 수 있어요.

## 📌 주요 기능

| 구분 | 내용 |
|---|---|
| 📅 캘린더 | 바탕화면 위젯, 공휴일 표시, 날짜별 메모·반복 일정, 팀 없이도 사용 가능 |
| ⚽ 경기 | 응원팀 경기 일정 자동 표시, 종료 경기 스코어, 승·무·패 스코어 색, 스코어 숨기기 |
| 🔍 팀 선택 | 5대 리그 + 포르투갈·네덜란드·K리그1·MLS 참가팀 목록, 이름 검색, 여러 팀 등록 |
| 📊 경기 상세 | 기본 정보·이벤트·라인업·순위 탭, FotMob 원본 보기 |
| 🎨 디자인 | 배경·글자·강조색, 투명도, 글꼴, 주말·공휴일 색, 실시간 미리보기 |
| ⚙️ 편의 | Windows 시작 시 자동 실행, 시간대·시즌 설정, 자동 업데이트, 피드백 |

## 💻 지원 환경

- Windows 10 / 11 (x64), .NET Framework 4.8
- FotMob 원본 보기 창에는 Microsoft Edge WebView2 Runtime이 필요할 수 있어요.
